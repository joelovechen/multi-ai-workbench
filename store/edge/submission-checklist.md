# Edge 0.4.2 提交清单

## 代码与包

- [ ] `manifest.json` 与 `package.json` 均为 `0.4.2`。
- [ ] 中英文 `_locales` 随 ZIP 打包。
- [ ] `npm test`、`npm run verify`、`npm run package` 全部通过。
- [ ] 使用干净 Edge 配置加载 `dist/multi-ai-workbench-unpacked`。
- [ ] 安装包根目录直接包含 `manifest.json`，不额外套目录。
- [ ] ZIP 不包含原始参考插件、测试登录数据、源码映射或开发临时文件。

## 商店资料

- [ ] 中文详情使用 `listing.zh-CN.md`。
- [ ] 英文详情使用 `listing.en-US.md`。
- [ ] 单一用途、权限理由和数据使用回答使用 `permission-justifications.md`。
- [ ] 审核备注使用 `certification-notes.md`。
- [ ] 隐私政策 URL 可公开访问且与包内 `PRIVACY.md` 一致。
- [ ] 开源仓库已推送与 ZIP 相同的 `v0.4.2` 源码标签。

## 图片素材

- [ ] 商店 Logo 为正方形 PNG，建议 300×300，最低 128×128。
- [ ] 至少准备 3 张、最多 6 张真实功能截图，统一使用 1280×800 或 640×480。
- [ ] 截图覆盖：全屏多平台、侧栏切换、提示词操作/设置、首次隐私告知。
- [ ] 截图中不出现私人账号、历史聊天、邮箱、头像或敏感问题。
- [ ] 不使用参考插件的商店截图、名称、图标或宣传文案。

## 人工验证

- [ ] DeepSeek、豆包、腾讯元宝登录态和无登录态分别检查。
- [ ] Gemini 不加载 `/_/bscframe` 作为主面板。
- [ ] 豆包普通启动不错误恢复旧历史会话。
- [ ] 全屏与侧栏双向切换时只保留一种界面。
- [ ] 桌宠单击侧栏、双击全屏、拖动和大小设置正常。
- [ ] 右键翻译/总结/释义和 `Alt+Shift+P` 正常。
- [ ] 权限拒绝、网络失败和平台 DOM 改版时有明确降级提示。

## 发布顺序

1. 首次提交建议选择 Hidden，完成商店签名版本验证。
2. 审核通过后从商店链接安装，复测核心平台和权限弹窗。
3. 修复商店环境特有问题后再切换 Public。
4. 公开发布时同步 GitHub Release、README 和版本说明。
