# Microsoft Edge 商店详情（简体中文）

## 名称

多AI问答助手

## 简短说明

同时向多个 AI 官方网页提问，并排或在侧栏切换比较回答；支持本地提示词、历史、划线笔记与导出。

## 详细说明

多AI问答助手是一款免费、开源、本地优先的多平台提问与答案对比工具。输入一个问题后，可以把它发送到用户选择的多个第三方 AI 官方网页，并在全屏工作台中并排查看，或者在浏览器侧栏中通过标签切换查看。

主要功能：

- 同时向多个 AI 平台提问并比较回答。
- 全屏工作台最多显示 10 个平台，支持单行、双行、拖动排序和宽度调整。
- 原生侧栏一次显示一个平台，仍可同时向多个平台发送问题。
- 默认启用 DeepSeek、豆包和腾讯元宝，侧栏默认打开 DeepSeek。
- 支持 ChatGPT、Gemini、Claude、Kimi、智谱清言、千问、MiniMax、知乎直答、Copilot、Grok 等平台。
- 支持图片和常见文档附件；实际可用能力取决于目标平台。
- 选中网页文字后，可通过右键菜单或快捷键执行中英双向翻译、总结和通俗释义。
- 支持用户自行增加提示词操作、菜单分组、目标 AI 和快捷操作。
- 支持本地会话历史、问题导航、划线、笔记和内容摘取。
- 支持将用户主动选取的内容导出为 Markdown、PNG 或通过浏览器打印为 PDF。
- 支持可拖动的图片或动画桌宠入口；用户可选择只在支持平台显示，或授权后在普通网页显示。
- 顶部提供可关闭的“AI 工具精选”目录，其中部分链接为明确标注的推广链接；通过链接注册或付费时，开发者可能获得佣金。

隐私与数据：

- 本扩展不提供产品账号、会员或 API 密钥管理。
- 不包含广告 SDK、遥测、用户画像或第三方分析 SDK；可选推广目录不记录点击。
- 设置、历史、提示词、草稿、划线和笔记保存在当前浏览器中。
- 问题、选中文字和附件只有在用户主动执行发送操作时，才直接提交给用户选择的第三方平台。
- 扩展开发者不运行问题中转服务器，不接收用户的问题和回答。
- 推荐目录和图标从开发者维护的 GitHub Pages 与 Cloudflare Pages 获取，请求不包含问题、回答或扩展生成的用户标识。
- 第三方平台可能要求用户在其官方网页中登录，并按照各自的条款和隐私政策处理内容。

为在工作台中显示第三方平台官方网页，本扩展仅针对清单中支持平台的子框架请求移除 CSP、CSP Report Only 和 X-Frame-Options 响应头。规则不修改普通顶层网页、请求正文、Cookie 或登录凭据。若平台改版或暂时不能嵌入，用户仍可通过面板中的“新标签页打开”继续访问该平台。

本扩展是独立开发的开源工具，与所支持平台不存在隶属、授权或合作关系。相关名称、商标和图标归各自权利人所有，仅用于识别用户选择的目标服务。
